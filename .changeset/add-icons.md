Add `@dexa-ui/icons`, a set of 52 solid icons (one filled path each, 24 × 24 grid) exported as tree-shakable data (`iconCheck`, `iconChevronDown`…) and as SVG files, plus `iconSvg()` for plain HTML. Add the Icon component (`DxIcon` in Vue and React, `<svg dx-icon>` in Angular): sized and colored like the surrounding text, `size`, `color`, `spin`, `label` for an accessible name, icons from other sets via `{ path, viewBox }`, and direction icons mirrored under `dir="rtl"`. Spinners keep turning (slower) with reduced motion.
